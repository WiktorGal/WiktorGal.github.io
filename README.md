# Wiktor Gałązka — portfolio

Personal portfolio at https://wiktorgal.github.io/, published from the root of `main` with GitHub Pages.

The original iPortfolio layout, photographs, portfolio gallery and contact form are retained. Updated CV content lives in `index.html`; the downloadable CV is `assets/docs/Wiktor_Galazka_CV.pdf`.

`assets/css/cv-update.css` adds only the CV download link styling, text-based skill groups and small responsive adjustments. The original `style.css` and `main.js` are unchanged.

For a local preview, run `python -m http.server 8000` from the repository root.

Original template: [iPortfolio by BootstrapMade](https://bootstrapmade.com/iportfolio-bootstrap-portfolio-websites-template/).
